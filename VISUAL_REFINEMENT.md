# L’Amour Gold — Visual refinement pass

This pass softens decorative borders from saturated yellow/gold to antique bronze, uses champagne for section headings, improves muted text contrast, adjusts the gold button gradient, and prevents the Love / Spark / Evening tabs from overflowing narrow phones.

The Figma showcase remains a visual reference, not a pixel-perfect screen specification. Compare each screen on your device and provide screenshots for further layout matching.

## Run

Copy your existing .env (not included) into the project, then run `npm install` and `npx expo start --go --clear`.
